## React + 타입스크립트 + vite
1. Menu --New Terminal 창 열기 (ctrl+shift+`)
2. 현재 경로에서 프로젝트 생성 멸령어 입력하기
```
npm create vite .
npm create vite . -- --template react-ts
```
3. 설치가 완료되면, 실행(코드가 어떻게 보여지는지)
    - 로컬 서버 및 실행 ```npm run dev```
